## 具体例1：【コード例】「丁寧なループ」 vs 「内部実装への丸投げ」

他言語で推奨される「1行ずつ処理する丁寧な記述」が、Pythonではいかに非効率かを示す例です。100万個のデータから偶数を抽出する処理で比較します。

```python
import time

data = range(1000000)

# 1. 可読性を意識した丁寧なロジック（遅い）
start = time.time()
result_a = []
for x in data:
    if x % 2 == 0:
        result_a.append(x) # 毎回メソッドの名前解決と動的評価が発生
print(f"手続き型: {time.time() - start:.4f}秒")

# 2. リスト内包表記（速い：内部のC言語レイヤーで一括処理）
start = time.time()
result_b = [x for x in data if x % 2 == 0] # LIST_APPEND命令を直接実行
print(f"内包表記: {time.time() - start:.4f}秒")
```

## 具体例3：【コード例】「自前実装」 vs 「標準ライブラリ（itertools）」

複雑なループ処理を自前で書かず、C言語で最適化された標準ライブラリに「仕事を投げる」手法です。

```python
import itertools
import time

# 複数のリストの全組み合わせ（直積）を生成
list_a = range(100)
list_b = range(100)
list_c = range(100)

# 1. 自前の3重forループ（Pythonレイヤーでの評価が膨大）
start = time.time()
res1 = []
for x in list_a:
    for y in list_b:
        for z in list_c:
            res1.append((x, y, z))
print(f"自前3重ループ: {time.time() - start:.4f}秒")

# 2. itertools.product（C言語レイヤーでループを回す）
start = time.time()
res2 = list(itertools.product(list_a, list_b, list_c))
print(f"itertools活用: {time.time() - start:.4f}秒")
```
